Bem-vindo ao PROSPECTA

O que é PROSPECTA?

PROSPECTA é um sistema de gestão de oportunidades e vendas que organiza todo o fluxo de vendas em etapas estruturadas com atividades e aprovações obrigatórias.

Objetivo Principal

Garantir rastreabilidade total, responsabilidade clara e eficiência operacional em todo processo de vendas.

Fluxo de Oportunidades

Ciclo de Vida de uma Oportunidade

1. Criação

Um vendedor, analista ou gerente cria uma nova oportunidade com dados do cliente, valor e data esperada.

2. Etapas (Stages)

A oportunidade é dividida em etapas sequenciais (ex: Prospecção → Qualificação → Negociação → Fechamento).

3. Atividades

Cada etapa contém atividades específicas que precisam ser executadas (ex: Agendar reunião, Enviar proposta).

4. Aprovações

Algumas atividades requerem aprovação de um Gerente ou Admin antes de serem consideradas concluídas.

5. Conclusão

Quando todas as etapas são concluídas, a oportunidade é marcada como GANHA, PERDIDA ou CANCELADA.

Pontos Críticos

  • Aprovações obrigatórias: Se uma atividade requer aprovação, ela não pode passar para a próxima etapa sem aprovação explícita.
  • Sequência de etapas: As etapas devem ser completadas na ordem. Uma etapa não pode avançar enquanto a anterior não está 100% concluída.
  • Auditoria completa: Toda mudança é registrada com usuário, data e hora para rastreabilidade total.

Sistema de Permissões

Hierarquia de Roles

👑 ADMINISTRADOR (admin)

Acesso total ao sistema. Pode criar/editar/deletar qualquer recurso, gerenciar usuários e permissões.

👔 GERENTE (gerente)

Gerencia seu time de vendedores. Pode criar/editar oportunidades, aprovar atividades e ver relatórios.

📊 ANALISTA (analista)

Executa atividades atribuídas. Pode ver oportunidades pertencentes a seu gerente mas sem permissão de editar.

👁️ VISITANTE (visitante)

Apenas leitura. Pode consultar informações mas não pode criar ou editar nada.

Sobre as Permissões

  • As permissões são verificadas em cada ação
  • Usuários sem permissão recebem erro 403
  • Mudanças de permissão são auditadas
  • Permissões são verificadas em tempo real

Gerenciar Usuários

Criar Novo Usuário

  1. 1. Acesse Gerenciar Usuários
  2. 2. Clique em + Criar Novo Usuário
  3. 3. Preencha: nome, email, senha, role
  4. 4. Clique em Criar
  5. 5. Usuário recebe email com login
Criar Usuário

Editar Usuário

  1. 1. Acesse Gerenciar Usuários
  2. 2. Clique no usuário desejado
  3. 3. Modifique os dados (nome, email, role)
  4. 4. Clique em Salvar
  5. 5. Alterações são auditadas
Ver Usuários

Desativar/Ativar Usuário

Em vez de deletar um usuário, você pode desativá-lo. Usuários desativados:

  • Não podem mais fazer login
  • Aparecem na lista mas marcados como "Inativo"
  • Histórico e dados são preservados para auditoria
  • Podem ser reativados a qualquer momento

Boas Práticas

  • Sempre defina um role adequado ao criar usuário
  • Use emails corporativos válidos
  • Revise permissões periodicamente
  • Desative em vez de deletar usuários

Dicas e Boas Práticas

1. Organize Bem as Etapas

Crie etapas que reflitam realmente o seu processo de vendas. Cada etapa deve ter duração realista em dias.

2. Use Aprovações Estrategicamente

Marque atividades importantes (propostas, contratos) para requerir aprovação. Isso garante qualidade e controle.

3. Monitore Relatórios

Revise os relatórios regularmente para identificar gargalos, oportunidades lentas e equipes de alto desempenho.

4. Mantenha Segurança

Revise permissões periodicamente, desative usuários que saem da empresa e use senhas fortes.

5. Mantenha Dados Limpos

Periodicamente, revise e archive oportunidades antigas. Isso melhora performance e clareza dos dados.

6. Treine sua Equipe

Compartilhe este guia com sua equipe. Quanto melhor eles entendem o sistema, melhor será o uso.
