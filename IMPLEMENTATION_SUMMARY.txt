├─ Solução:

│  2. Ir para /admin/usuarios/
│  3. Mudar role do user para 'admin'

├─ Causa: Rotas não foram adicionadas
├─ Solução:
│  1. Verificar prospecta/urls.py
│  2. Confirmar import admin_views
│  3. Confirmar 6 rotas estão presentes

Problema: "Template não encontrado"
├─ Causa: Arquivo não existe ou local errado
├─ Solução:
│  1. Confirmar arquivos em prospecta/templates/prospecta/admin/
│  2. Rodar manage.py collectstatic
